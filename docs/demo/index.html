HUMAN BASELINE

10/10 人工规则对照

10/10 一致

每行是一张合成判断：先写人工结论，再跑同一条规则引擎，最后逐条比对。3 条硬约束失败即不可制造；其余为工艺复核。

REQUEST LIFECYCLE

一次判定的完整路径

  1. 01
    选择纹样与参数

    UI 只收集输入，不伪造结果。

  2. 02
    POST /api/check

    服务端校验工艺、材料、表面、数量、授权和 10 条规则。

  3. 03
    返回逐条证据

    每条规则 pass / fail / 不适用，附条件与实测值；硬约束失败即阻断。

  4. 04
    创建订单快照

    授权、参数、报价、判定写入订单；创建动作写入审计。

  5. 05
    角色迁移状态

    每次迁移检查角色与前置状态，版本号递增，事件追加。
