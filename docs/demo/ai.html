# FDE 驻企交付手册（演示版）

适用：六产业共享企业 AI 服务层 · 珠宝定制 / 木作定制两类行业配置。本文是合成样例交付方法，不构成对真实客户、真实产能或法律效力的承诺。

0. 交付边界与前提

  • 交付物：本地规则引擎（关键词 / 字符 n-gram 检索 + 意图路由）、知识库、智能体会话、自动化工作流、三语站点文案、询盘 CRM、本手册与验证记录。
  • 明确不做：不接入外部大模型，不发送真实邮件 / 短信，不做支付与电子合同，不做多租户隔离，不承诺真实交期与价格。
  • 前提：企业指定一名业务负责人（知识库 owner）与一名 IT 接口人；提供可公开的合成样例数据用于联调；生产域名与备案由企业负责。
  • 成功定义：业务人员能在不写代码的前提下维护术语、知识、工作流模板与站点文案；每条 AI 回答可回溯到文档 / 版本 / 片段。

2.2 清洗规则（当前实现）

  • 文本统一去首尾空格；连续空行折叠为段落分隔；单文档上限 12000 字符，超出拒收并提示拆分。
  • 邮箱统一小写并做格式校验；不通过则返回 422，不写入线索。
  • 行业、语言、阶段均取自数据文件白名单，非法值返回 422，避免脏数据进入检索。
  • 文档自动切块：按段落与句号切分，单块不超过 180 字符；块 ID 形如 c1，引用格式 docId#c1。
  • 未做：去重合并、PII 自动识别、富文本 / PDF 解析、图片 OCR。这些需在生产接入时补，当前演示仅接受纯文本。

2.3 脱敏与合规

  • 演示数据全部为合成姓名、example.com 邮箱与虚构企业，不含真实个人信息。
  • 生产导入前须删除身份证号、银行卡号、私人手机号；如必须保留，需加密存储并限制导出权限。
  • 日志只记录线索 ID 与阶段变更，不记录完整留言正文，避免审计日志成为二次泄露源。

3. 知识库运维与版本

  • 状态机：draft（草稿，不参与检索）→ published（已发布，检索可见）→ retired（已下线，保留引用）。
  • 版本：每次内容变更必须递增版本号（如 v1.2 → v1.3），并在变更说明中写清改了什么、依据是什么。
  • 切块复核：发布前人工抽查至少 3 个块，确认没有把否定句、例外条款切断；问答类文档应保持“问题 + 答案”在同一块内。
  • 引用可追溯：回答只允许引用 published 文档；引用包含 docId、版本与 chunkId，客户可见文档标题与片段。
  • 月度复核：owner 每月检查一次价格、工期、售后条款；过期内容先改 retired，再发布新版，禁止直接覆盖历史版本。
  • 失效处理：发现错误回答时，先下线对应文档，再在事件记录中标注影响范围；不要只改页面文案。
  • 权限：仅 ops 与管理員可写；设计与财务可检索；工坊只读；客户 / 销售可检索与建线索。

6. SLA 与服务等级（演示口径）

  • 服务时间：工作日 09:00–18:00（Asia/Shanghai）；演示环境不承诺 7×24。
  • 可用性目标：99.5% / 月；计划维护提前 1 个工作日通知。
  • 故障分级：P1（全站不可用）30 分钟响应、4 小时恢复；P2（核心流程受阻）2 小时响应、1 个工作日恢复；P3（展示 / 文案问题）1 个工作日响应。
  • 数据备份：SQLite 每日快照，RPO ≤ 24 小时、RTO ≤ 4 小时；备份文件与密钥分离存放。
  • 变更窗口：生产知识库与工作流模板变更需 owner 审核；高风险变更在低峰期执行并保留回滚版本。
  • 以上为演示目标，正式合同须由企业 IT 与法务确认后生效。

7. 退出与交接

  1. 数据导出：文档、线索、工作流运行、审计事件按 JSON / CSV 导出，附带 schema 与字段说明。
  2. 账号回收：停用驻企账号，移交管理员账号；撤销 API 凭证与备份访问权限。
  3. 知识归档：保留最终版与最近三个历史版本，标注 owner 与生效日期；其余版本按企业留存策略销毁。
  4. 交接清单：配置说明、知识台账、工作流清单、未关闭问题、SLA 记录、联系人。
  5. 过渡期：不少于 30 天并行支持；交接完成后由企业书面确认，驻企人员退出。

8. 已知边界

  • 检索是关键词 / 字符 n-gram 匹配，不做语义向量；同义改写、长句推理能力有限，需靠术语表与文档标题补足。
  • 智能体是本地规则路由，不是大模型；不会生成开放式创作，只做检索引用、线索登记、工作流草稿三类动作。
  • 工作流重试按整条流程重跑；若失败发生在写 CRM 之后，可能产生重复线索，生产接入需增加幂等键。
  • 通知仅写入站内模拟记录，不发送邮件 / 短信；报价草稿为区间建议，必须人工复核后才能对外。
  • 页面未做移动端深度适配与无障碍全量审计；演示数据未加密，禁止放入真实客户信息。
